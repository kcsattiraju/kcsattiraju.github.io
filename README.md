# Projects

This repository contains the source for the portfolio website and its project examples.

## Insurance AI Copilot

[Read the complete technical capabilities, architecture, and setup guide](insurance-ai-copilot/README.md).

The project combines a Streamlit chat UI, a LangGraph agent powered by Amazon Bedrock, hybrid PDF retrieval, and PostgreSQL conversation history. Its Python source is in [`insurance-ai-copilot/`](insurance-ai-copilot/). Run it locally using the project guide; GitHub Pages hosts static files and does not execute the chatbot backend.
