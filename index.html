Insurance AI Copilot

An AI-powered insurance assistant built with Python and Amazon Bedrock to explain coverage, deductibles, and policy terminology. The project also explores agentic workflows and retrieval-augmented generation for answering questions using insurance documents.

  • Amazon Bedrock with Amazon Nova Lite for natural-language insurance explanations
  • LangGraph-based agent workflows and insurance-specific tools
  • Hybrid retrieval using Chroma vector search, BM25, and Reciprocal Rank Fusion
  • PostgreSQL-backed conversation history and context-window management
  • Streamlit chat interface under development
  • Policy-grounded answers and document retrieval integration in progress

Technologies: Python, AWS Bedrock, LangGraph, Chroma, BM25, PostgreSQL, Streamlit
